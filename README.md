# CraftLoom · 织途

**Minecraft 知识库与成长引导**

从第一次生存到复杂自动化，连接知识、解释原理，陪玩家一步步实现自己的目标。

## 项目状态

当前处于工程准备阶段，尚无可用 Mod 或核心服务。下列内容为设计目标，不代表已实现。

首发目标为 **Minecraft 1.20.1 Forge**；**1.12.2 Forge、1.7.10 Forge** 是必须后续覆盖的版本。

## 设计方向

- 结合实际配方、任务进度和玩家目标，提供有来源、可解释的引导。
- 建立带双向关联、版本条件、冲突记录与社区贡献的知识库。
- 游戏内提供上下文帮助；Web 提供完整知识工作台；Agent 通过 MCP 使用同一核心能力。
- 按需读取游戏状态与库存，避免无差别扫描和向模型发送大量数据。
- 通过界面提示、结构投影和阶段检查帮助玩家理解与实践。
- 告示牌作为方案锚点：先投影检查，再单独决定是否搭建；保留关、投影、消耗物品搭建、不消耗物品搭建四档。
- 多人由房主承载共享知识和公共目标，玩家下载缓存，个人模型与私人数据留在本地。

## 独立运行与开放接入

CraftLoom 拥有独立仓库与发布流程，不依赖特定启动器。
AMCL 为官方支持的启动器接入端；计划通过 MCP 支持外部 Agent，并逐步适配
DeepSeek Harness、Claude Code 等环境。

观察、行动与任务接口将为 AI 通关、多角色协作及 RTS 式玩法保留扩展位置；这些不属于首版验收范围。

## 工程布局

| 目录 | 用途 |
| --- | --- |
| `protocol/`、`schemas/` | 通信协议和数据格式 |
| `game/` | 各版本游戏端与共用逻辑 |
| `integrations/` | 配方查看器、任务、机器与存储适配 |
| `core/` | 独立核心服务 |
| `web/` | 知识工作台 |
| `connectors/` | MCP 与启动器接入 |
| `tests/fixtures/` | 协议和游戏数据样例 |
| `docs/` | 设计、开发与贡献说明 |

当前目录为占位，没有可运行的构建命令。技术栈已确定，依赖版本将在实现时锁定。

## 技术栈

| 部分 | 选型 |
| --- | --- |
| 游戏端 | Java、Forge 1.20.1、Gradle；旧版本独立适配 |
| 核心服务 | Python 3.12、FastAPI、Pydantic |
| Web | TypeScript、React、Vite |
| 存储 | SQLite 与文件目录 |
| 本地接口 | HTTP 查询与操作、WebSocket 事件推送 |
| 多人通信 | MC 自定义消息，复用游戏连接 |
| Agent 接入 | 官方 Python MCP SDK，复用核心业务层 |
| 检查 | pytest、Ruff、TypeScript 检查与 Gradle 构建 |

预留 Rust 计算模块接口，性能测量确认热点后再引入；首版不要求 Rust 工具链。
发布目标是打包核心服务并附带 Web 静态文件，普通玩家无需自行安装 Python 或 Node.js。
详见 [技术决策](docs/technology-decisions.md)。
